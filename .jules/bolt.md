## 2024-09-24 - Precompiled NSRegularExpression over dynamic String methods
**Learning:** Using `String.range(of:options: .regularExpression)` or `replacingOccurrences(of:options: .regularExpression)` in Swift is convenient but compiles the regex dynamically every time it is called. Inside loops (e.g., in `extractSeriesTitle` processing large arrays of recommendations) or view lifecycle events, this can become a significant performance bottleneck and block the main thread.
**Action:** Always precompile static `NSRegularExpression` instances inside a `do-catch` block (and `fatalError()` since they are constants) to use methods like `firstMatch` or `stringByReplacingMatches` instead. Make sure to map between Swift `String.Index` and `NSRange` safely using `NSRange(string.startIndex..<string.endIndex, in: string)`.
